# Imagem remota em HTML cru

Com HTML cru ligado e imagens remotas desligadas, esta imagem não pode ser
pedida ao servidor — é um pixel de rastreio tanto quanto uma imagem Markdown
seria — e tem de aparecer no aviso de bloqueadas, não sumir em silêncio.
